# Airbnb Clone

A full-stack Airbnb-inspired web application built using the MERN stack.

## Tech Stack

- MongoDB
- Express.js
- React.js
- Node.js

## Features

- User Registration and Login
- Property Listing
- Property Search
- Property Details
- Booking System
- Reviews and Ratings
- Host Dashboard
